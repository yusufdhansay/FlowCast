# FlowCast — Urban Mobility & Traffic Intelligence

FlowCast is an end-to-end data science project for analyzing
urban traffic conditions, forecasting road-segment speeds,
and identifying recurring congestion bottlenecks.

## Data source

NYC DOT Traffic Speeds:
https://data.cityofnewyork.us/Transportation/DOT-Traffic-Speeds/i4gi-tjb9

## Project status

Phase 0: Initial dataset feasibility validation completed.
Phase 1: Data ingestion and project infrastructure in progress.

## Planned capabilities

- Reproducible ingestion of historical traffic observations
- Data quality validation and PostgreSQL storage
- Temporal and geospatial traffic analysis
- Short-horizon traffic speed forecasting
- Road-network bottleneck analysis
- Decision-support dashboard

## Important limitations

Traffic status codes and measurement validity require further
verification. Forecasting and descriptive analysis do not establish
the causal impact of transportation interventions.
